# Zero-Trust Home

Private, local-first smart home control (on the phone: **ZT Home**). Part of
the Zero-Trust suite, built on
[Zero-Trust-Core](https://github.com/EdoSag/Zero-Trust-Core), and end-to-end
encrypted like the other apps.

Work happens on the `Dev` branch; releases are one `Dev` → `main` pull
request.
